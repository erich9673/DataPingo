System requirements

  • Active Confluence Cloud instance
  • Modern web browser (Chrome, Firefox, Safari, Edge)
  • Active internet connection
  • Appropriate Confluence permissions

Permissions required

Six scopes, and no others:

  • read:page:confluence — read the page you pick as a source, so it can be listed, previewed and copied.
  • read:space:confluence — list the spaces you can already see, so you can choose where copies land.
  • write:page:confluence — create the new pages.
  • read:label:confluence — read the source page's labels so they carry across to every copy.
  • write:confluence-content — used by Confluence's own copy API, which duplicates attachments, macros and page properties server-side.
  • storage:app — the app's own storage on Atlassian's platform. Holds your saved template snapshots and a short-lived cache of your page list (5-minute expiry). It stays inside Atlassian — nothing is sent to DataPingo.

No admin rights needed. The app acts as you and can only ever see and create pages you already have access to. It does not request space administration or site administration permissions.

Cloud only: Bulk Page Cloner is built on Atlassian Forge and runs exclusively on Confluence Cloud. Confluence Server and Data Center are not supported.

Privacy & security

  • Data Privacy: DataPingo Privacy Policy
  • Security: DataPingo Security Policy
  • Data Storage: All app data is stored in Atlassian Forge Storage — no data is sent to or stored on external DataPingo servers
  • Media Handling: Pages are duplicated by Confluence's own server-side copy, so attachments, labels and page properties move inside Atlassian's infrastructure — never through an external server DataPingo operates
  • Customer information: We receive customer details only through the Atlassian Marketplace. We do not sell, distribute or share that information.
  • GDPR status: Atlassian has approved our declaration that DataPingo is neither a data controller nor a data processor under the GDPR with reference to this app. Verify it yourself on the Privacy & Security tab of the Marketplace listing.
  • Compliance: Follows Atlassian security standards and the Forge platform security framework
