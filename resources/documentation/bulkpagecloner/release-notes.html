Release Notes

v10.0.0 Latest July 23, 2026

A permissions-only release. Cloning, the interface and data handling are identical to 9.0.0.

  • One fewer permission — search:confluence has been removed. The app never called Confluence’s search API, so the scope was never needed.
  • The searchable parent picker still works — it loads the pages in your space and filters them in your browser, which never used the search permission.
  • No functional changes — cloning, the template picker, labels, attachments, macros and page properties all behave exactly as before.
  • Runs on Atlassian preserved — still no external network access, and no data leaves your Confluence instance.

Your admin may need to approve the upgrade. Because the required permissions changed, Confluence may ask a site admin to confirm before the new version installs.

v9.0.0 July 19, 2026

A maintenance release. Cloning behaviour, the interface and data handling are identical to 7.1.0 — this release only reduces what the app asks for.

  • Fewer permissions — the app no longer requests the email-address scope.
  • No external network access — every operation runs on Atlassian infrastructure, and no data leaves your Confluence instance.
  • Runs on Atlassian verified — the app meets Atlassian's criteria for the Runs on Atlassian badge.
  • No functional changes — nothing to relearn, and no action needed on your side.

Where did 8.0.0 go? Version 8.0.0 was withdrawn shortly after release and never became generally available. Version 9.0.0 supersedes it.

v7.1.0 Feature release July 6, 2026

A ground-up redesign of the cloning experience:

  • Guided 4-step flow — A clear Source → Copies → Location → Done flow with a progress bar and a live clone summary that builds as you go, so you review everything before you create.
  • Full dark mode — Light and dark theme support that matches your Confluence theme and switches live, no reload needed.
  • Smarter & safer — A heads-up when a source page @mentions people (each copy notifies them again), plus warnings for large batches (10+ pages) and duplicate titles before Confluence auto-numbers them.
  • Search-first picking — A searchable space and parent-page selector that loads every page in the space, an editable copy count, and clearer wording using Confluence's own parent/child terms.
  • Faster under the hood — Caching and rendering improvements across the cloning pipeline.
v7.0.0 June 22, 2026
  • Attachments & video now copy — Copies are made through Confluence's own copy API, so images, files and embedded video come across intact instead of showing "Preview unavailable".
  • Searchable parent picker — Pick any page in the space as the parent, with search across the full page list.
  • Speed boosts — Faster page loading across large spaces.
