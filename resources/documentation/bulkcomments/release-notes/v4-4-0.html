On this page

Release date: September 3, 2026  ·  Version: 4.4.0

Enhancements

Licensing

  • Renewal opens the Pricing tab — Renew on Marketplace used to open the listing’s Overview page, whose only button is Try it free. A site that has already used its evaluation cannot start a second one, so that button failed for exactly the person being shown the notice. It now opens Pricing, where Get it now creates the subscription.
  • The free tier is named — 10 users or fewer costs nothing, but a trial does not roll into the free tier by itself and nothing said so. The wording now matches Bulk Page Cloner, so both apps read the same.

Fixes

Wording

  • A one-ticket send reads as one — sending a single comment reported “Comments posted.” It now says Comment posted, and likewise Ticket updated and Status change applied for a single ticket.
